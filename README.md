# ATHASH Digital Solution

Athash Digital Solution is a modern company website for a South African brand and digital services business. The site showcases core offerings, explains the company’s value proposition, and helps visitors get in touch quickly through WhatsApp.

Live site: https://spvngcobo.github.io/ATHASH-DIGITAL-SOLUTION/

## Overview

Athash helps businesses and institutions move from idea to growth through:

- Brand strategy and visual identity
- Website development and digital presence
- Business setup and registration support
- Digital marketing and online growth
- Custom digital systems and document automation
- School branding and institutional communication materials

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Lucide React icons
- Static export for GitHub Pages

## Local development

From the `athash-website` folder:

```bash
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

## Production build

```bash
cd athash-website
npm run build
```

The project is configured for static export and GitHub Pages deployment.

## Deployment

This project is published to GitHub Pages using a static Next.js export configuration. The repository includes a `basePath` setup for the site to work correctly under:

`/ATHASH-DIGITAL-SOLUTION`
